# WebDoYouMean

Coursework from MEDA 101 (Web Design), taught by Eduardo, 2021 to early 2022. Hand-written HTML, CSS and a little JavaScript: an about-me page, a gallery site, a four-page "first official website", Bootstrap and Font Awesome labs, forms, tables, CSS grid, and the JavaScript homework (FizzBuzz, chessboard, times table).

This repo is kept as a record of where the web work started. It is not maintained. For current work see [oscar-leung.github.io](https://oscar-leung.github.io).

## Look around

Open any `.html` file in a browser; there is no build step.

| Path | What it is |
|---|---|
| `index.html`, `official_webpage.html` | The about-me page, before and after W3C validation |
| `first-official-website/` | Four-page site with a shared stylesheet |
| `gallery_website/` | Gallery, menu and contact pages |
| `homework/`, `lab/` | JavaScript exercises |
| `bootstrap*.html`, `font-awesome.html`, `grid.html`, `forms_with_css.html` | Framework and layout labs |
| `Hobby Part 1/` | Images and copy for the board-game hobby page |
